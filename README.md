# Composite Simpson's 1/3 Rule – Numerical Methods Online Calculator

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![Flask](https://img.shields.io/badge/Flask-3.0.3-green)](https://flask.palletsprojects.com/)
[![Deployed on Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-black)](https://vercel.com)

A Flask web application that demonstrates the **Composite Simpson's 1/3 Rule** for numerical integration.  
It provides:

- A clear mathematical explanation (with LaTeX formulas using MathJax)
- Two fully worked, step‑by‑step examples
- An interactive calculator where users can enter any function \( f(x) \), limits \( a \) and \( b \), and an even number of subintervals \( n \)
  to get the approximated integral.

**Tech stack:** Python, Flask, HTML/CSS, MathJax, Vercel (deployment)

**Link:** https://composite-simpsons-13-rule.vercel.app/
